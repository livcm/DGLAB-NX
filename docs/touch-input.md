# 触屏玩法

屏幕左半驱动 A、右半驱动 B；越高波形值越大，每半区内越靠右脉冲越密，拖动速度不参与。
2026-09-19 用户确认触屏可运行，端点可达范围已量，手感仍待调。
触屏只在玩法页读取，不用于菜单；映射/上传与界面已实现，见 `tests/touch`、`tests/canvas`。

## 输入依据

已核对 libnx `switch/services/hid.h`、hid.o 反汇编与官方 `hid/touch-screen` 示例。
平台 API 只在 `nro/source/platform/touchscreen.c`；映射在 `touch/touch_feed.c`，
与体感共用 `motion_feed` 的包络/25ms 槽位，经 NET_WAVEFORM 上传，现有 IPC 足够。

- hidInitializeTouchScreen 没有 Result，初始化失败会致命退出，不能随手在启动或菜单调用。
  读取前 hid 共享内存必须存在，缺失同样 abort；NRO 手柄初始化已提供它。
- 状态环 17 条；读取批次、合并边沿与坐标具体实现查平台文件。
- 坐标按 1280×720 逻辑单位使用，底座缩放由 canvas 负责；屏幕代码不乘比例。
- 底座下触屏不可操作，页面隐藏整个玩法图形并提示取下主机，按键仍可用；
  operation mode 判定在 applet 环境是否可靠仍需专项实机确认。

## 区域与交互原因

页头线 y=87、底栏线 y=647 同时作纵轴端点，分别对应波形值 100/0。
越出端点夹紧，页头带可达满值、底栏为 0；有效幅度仍受用户通道强度与上限控制。

横轴外端采用页面线端点 x=24/1255，内端在中线 x=639/640。
2026-09-19 实机手指最多靠近屏幕边缘约 20px；若用物理边缘作端点，30~100ms
只摸到 32~98ms，故改为可达的线端点。内端保留中线是用户选择；若实机难够再考虑内端死区。
常量与映射公式以 `touch_panel.h` 为准，不重复维护网格坐标。

每半区一指，新按下接管；同帧多个新指用读数顺序决定，面板无帧内按压时间戳。
当前指离开可由同区其它指接管；跨中线释放原通道并启动另一通道，左右可同时驱动。

抬手后保留最后波形目标/密度，波形值沿 release 回落；密度不归零，避免尾巴突然变稀。
归零且超过 idle_stop 才停上传；按在波形值 0 的底栏不产生流量。

## 参数复用

触屏没有独立参数文件，使用 `config/motion.cfg`，由 motion_settings 唯一读写：

| 共用参数 | 触屏含义 |
| --- | --- |
| attack / release / idle_stop | 跟随、抬手回落、回落后停上传 |
| freq fast / still | 可变密度时半区右/左端的脉冲间隔 |
| density / fixed density | 固定时横轴不影响间隔；波形值、包络、停流不变 |
| strength max | 满纵轴对应的波形值 |
| 死区/量程/权重 | 不参与触屏，仅体感使用 |

可变密度由玩法选择驱动：体感随运动值，触屏随横坐标；这是运行时模式字段，不能当文件参数。
强度行/上限与其它页共用语义，见 [README](../README.md#强度与-ble-前提)。

## 界面与平台约束

玩法区满幅，但墨迹必须留在两条横线内；触点在显示框内夹紧，外侧夹紧带不画量程刻度。
固定密度时隐藏横轴刻度和端点竖线，保留中线与纵轴；主题取现有字段，不新增调色板。
底座模式用测量后的空间居中显示提示，不保留可误导的网格。

Makefile 按 basename 展平源文件目标，平台文件名必须与 UI 文件不同；
`platform/touchscreen.c` 和 `ui/touch.c` 不能都叫 touch.c。
日志写入 net 文件，进入及半区触点状态变化时记录 LIFO/原始坐标与映射结果，不按帧刷屏。

## 实机验收与待确认

主机入口：`make -C tests/touch`、`make -C tests/canvas`。
实机检查相册/title override 两种启动、坐标方向与范围、左右独立输出、多指接管、跨中线、
页头/底栏夹紧、抬手淡出/停流、可变密度两端极值、固定密度画面/间隔，以及底座提示和按键。

仍待确认：读取数组最新快照的方向、稳态每帧快照数/attributes、坐标抖动、压力/手掌影响、
两种启动初始化结果、30ms 手感与波形上限、中线极值好不好触达、底座 operation mode 判定。
若底座提示不出现再评估已有 framebuffer scale 信号，不能先声称已可靠。
