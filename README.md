# DGLAB-NX

Nintendo Switch Atmosphère 环境下的 DG-LAB 控制器，非官方第三方实现。
目前可用的是 NRO 前端与常驻后台服务；Overlay 和 Game Mod 尚未实现。

| 模式 | 连接方式 | 使用条件 |
| --- | --- | --- |
| WebSocket（Socket V3） | 手机 DG-LAB App 扫码连接 Switch，手机再连接设备 | 主力模式，手机与 Switch 在同一局域网 |
| BLE 直连（Coyote V3） | Switch 后台直接连接设备 | 需匹配固件的 exefs 补丁；只能开环控制，无法读取真实强度或电量 |

## 安装

需要 Atmosphère，已验证环境为 HOS 22.5.0 + AMS 1.11.2。
将发行包 `DGLAB-NX-<版本>-sd.zip` 解压到 SD 卡根目录；覆盖安装也相同。

- `atmosphere/contents/<TITLE_ID>/` 是后台服务；保留发行包中的目录名。
- `switch/DGLAB-NX/` 是前端，**整个目录一起复制**，包含 `.nro` 与 `lang/`。
  没有可用语言文件时前端会报错退出；`config/`、`logs/` 由程序创建。

复制后弹出整块磁盘再拔卡（macOS 用 Finder「推出」或 `diskutil eject /dev/diskN`），
然后重启 Switch，后台服务才会加载新版本。
BLE 补丁的版本、安装和撤销方法见 [BLE 文档](docs/ble-re.md#诊断补丁)。

## 使用

### WebSocket

1. 手机与 Switch 连接同一个局域网。
2. 打开 `DGLAB-NX.nro`，选择 `socket server`，按 A 启动服务端。
3. 用 DG-LAB App 扫描二维码连接，并确认 App 已连接设备。
4. 从 0 逐步调高通道强度，用测试按钮或玩法页确认输出。

服务端不会开机自启；最后一个客户端离开 55 秒后会自动停止。
**测试按钮会实际输出电压**，请先确认设备、电极连接正常，再逐步增加强度。

### 页面与按键

菜单用十字键上下选择、A 进入、B 退出 NRO。Console 页用 + 退出。

| 页面 | 用途与操作 |
| --- | --- |
| `socket server` | A 启停服务端，Y 看日志，X 清空波形，B 返回；ZL/ZR 测试 A/B；↑↓ 调 A 强度，→← 调 B 强度 |
| `bluetooth (direct)` | A 起 BLE 会话，X 停止，Y 看日志，B 返回；十字键调两路强度。**返回后会话继续运行**，可进入玩法页；退出 NRO 时停止 |
| `motion (Joy-Con)` | 左右拆下的 Joy-Con 分别驱动 A/B，动作越大波形值越大、脉冲越密；操作同 socket 页，Y 重新扫描手柄 |
| `touch (screen)` | 左半屏驱动 A、右半屏驱动 B；越高波形值越大，每半区内越靠右脉冲越密，抬手淡出；按键同 socket 页，但没有日志键。底座模式显示无法触摸，按键仍可用 |
| `advanced (motion)` | ↑↓ 选参数、←→ 改值、Y 恢复默认、B 返回；设置自动保存，体感与触屏共用，死区/量程/权重仅用于体感 |
| `about` | ↑↓ 滚动、←→ 切语言、Y 切主题、B 返回；显示应用版本、IPC 版本和构建标识 |
| `BLE PoC console` | 诊断控制台，操作步骤见 [BLE 验证](docs/ble-poc.md) |

触屏只用于触屏玩法，不能操作菜单。密度设为「固定」后，动作或横向触点不再改变脉冲间隔。

### 强度与 BLE 前提

强度行显示 **值/上限**，如 `20/80`。两路独立，从 0 开始，调整后立即发送，按住连续调整。
Socket/体感/触屏页优先使用 App 上报的上限；未上报时用高级参数的上限，蓝牙页使用参数页上限。
通道强度是幅度设置，波形值由动作或触点决定。

BLE 直连还必须满足：

- 安装匹配的补丁，设备没有手机绑定信息（关闭 App 的「设备绑定」或重置设备）。
- **一个开机周期只走一条 BLE 路径**；再次连接或跑另一探针前先重启，混用可能导致整机崩溃。
  停 BLE 后可用 Socket 模式，它不操作 Switch 蓝牙栈。
- 两通道上限分别控制输出幅度，上限为 0 的通道无幅度输出。会话自带默认波形，
  因此强度为 0 时灯也可能闪；灯闪不等于有可感输出。

BLE 会话运行时，玩法页的 X 清空请求当前不会清掉会话波形；需回蓝牙页按 X 停会话。
会话跨页玩法已有代码，仍待实机确认，见 [验证状态](docs/ble-poc.md#当前状态)。

## 限制与排查

- **WebSocket 服务端运行时不要手动休眠**，会卡死主机，需长按电源恢复。先停服务再休眠。
  NRO 运行期间会抑制自动休眠；退出 NRO 后服务端仍在运行时，自动休眠也可能卡死。
- 只实现 Socket V3，V4 外壳未实现；同时只绑定一个 App。
- BLE 依赖补丁且无回读；补丁尚未纳入发布包。不能将界面请求值当成设备实际状态。
- Overlay、Game Mod 尚未实现，其余验证边界见 [开发文档](docs/development.md)。

按键无效先看 `last cmd`：红色表示失败，黄色表示命令已发但该路强度仍为 0。
无输出时检查通道强度、对应上限、有效波形、设备连接；BLE 还要检查设备绑定与补丁。
排查日志在 `SD:/switch/DGLAB-NX/logs/dglab-net.log`；BLE 日志需在同次开机、关机前由 NRO 读出落盘。
